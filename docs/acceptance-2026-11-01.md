## 修复内容

1. 客户端必须已注册，回调严格匹配；关闭未实现的 Client ID Metadata Document 声明。Access 身份认证之后增加独立、一次性、同源且绑定身份的授权确认。
2. 授权码原子消费，刷新令牌原子标记已用，重放撤销令牌家族，检查资源绑定和权限提升。真实 D1 的测试专用键验证了“首次成功、第二次无结果/无更改”，结束后移除该键，未读取或篡改真实令牌。
3. 中文及英文搜索统一使用解码后的字段，组合筛选保留 AND，支持文本/HTML 正文；扫描不完整时给出 `partial`、准确性标记和续扫游标，不再把局部结果冒充完整总数。
4. 移除文件夹级 EXPUNGE/CLOSE 兜底；没有安全定向能力时返回待清理状态，不触碰无关邮件。
5. 草稿发送原子防重；区分已发送、保留、隐藏和物理移除，避免发送成功后因清理失败诱发再次发送。
6. 回复状态重新选择原文件夹并回读；返回线程关联头。转发缺失附件时在发送之前失败。
7. 实测发现 HTML-only 草稿存在空纯文本部分导致阅读空白，2.0.4 修复新草稿生成和历史邮件 HTML 回退，并覆盖回复引用。
8. 启用错误观测，日志仅事件/工具/错误类型，不记录正文、令牌或完整堆栈；请求级 invocation logs 关闭。

## 发信闭环及样本清理

实际成功 SMTP 投递 **8 封**，全部只发给邮箱所有者本人，无第三方收件人，无业务内容：新邮件1封、回复2封、转发2封、草稿发送3封。两次重复发送草稿请求被拒绝，没有增加投递。

样本主题为 `[MCP-203-R8]` 和 `[MCP-204-R8]`。已确认“已发送”中精确8封，与实际投递数一致。测试收件标记已读、取消星标后移入垃圾箱；MCP默认收件箱和草稿列表中搜索这两个前缀均返回0。“已发送”保留8封作为验收凭证，垃圾箱保留测试数据，未清空垃圾箱。

因QQ缺少UIDPLUS，部分源记录仍带删除标记，物理数量可能未下降，`include_deleted:true` 或其他客户端可能仍看到。没有对无关邮件执行修改，没有调用文件夹级清理。

内部排障索引（仅合成测试样本）：首次新邮件Inbox1520，移动至中文文件夹UID2，再移回Inbox1527；回复1521/1523；转发1522/1524；普通草稿收件1525；旧HTML草稿收件1526；最终HTML收件1528。测试草稿57、58、59、60；Sent副本126至133。UID不能跨文件夹使用。

## HTTP / 数据库校验

- 最终 `/health` HTTP200：version2.0.4、ready=true、Access JWT验证=true。
- OAuth发现与受保护资源发现HTTP200；CIMD支持声明false。
- 无令牌和伪造Bearer的MCP请求HTTP401，并提供认证发现信息。
- 无效刷新令牌HTTP400 `invalid_grant`，未触发邮箱操作。
- 无效下载链接HTTP404；有效合成样本链接HTTP200，附件处置、UTF-8文件名、nosniff、`default-src 'none'; sandbox`均存在。
- 真实D1测试键上INSERT OR IGNORE首次changes1、第二次0；刷新标记与DELETE RETURNING首次返回记录、第二次为空。

生产HTTP探测通过用户Cloudflare账号的Browser Rendering请求执行；没有通过绕过Access、植入测试访问令牌或关闭认证来制造成功结果。

## 自动测试覆盖与边界

88项包括授权允许/拒绝、CSRF来源/Cookie/身份约束、未注册客户端/错误回调、并发消费授权码、刷新重放/权限提升/资源不匹配、中文AND与正文、部分扫描及续扫、读取不改已读、邮件编解码、发送/回复/转发、Bcc隔离、草稿并发防重、无UIDPLUS不执行全文件夹清理，以及空白plain/HTML回退等。

2.0.4第一轮新增测试失败时没有部署。排查发现APPEND测试替身只保存原始邮件而不生成真实BODYSTRUCTURE；两项生成邮件验证改在真实生成的MIME/SMTP边界解码检查，保留历史邮件读取的回归测试，随后88项全部通过。最终HTML流程额外在真实QQ上读回，避免仅依赖模拟。

本次没有使用所有者的交互式浏览器重新走完整Access登录，新增确认页由自动测试覆盖；已有真实连接在升级后持续可用。未进行超大附件/持续高并发/长期稳定性压测，也未模拟真实邮件服务器的所有断线与延迟组合。直接send_email/reply/forward没有跨请求全局幂等保证，结果不确定时不要盲目重发。

## 运维提示

最近安全回退基线为2.0.3 Worker version `f925b109-ddf0-4884-82f9-ee37204bf0d5`（它仍有HTML-only阅读问题）；不要回退到存在授权与误清理风险的2.0.2。回滚后也必须检查绑定、版本、认证及自发自收。
